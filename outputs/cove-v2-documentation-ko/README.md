## 번역 및 기술 표기

문서 본문, 화면 설명, QA 사례·상태, 권한 설명, 시퀀스 레이블 및 주요 기술 부록을 한국어로 제공했습니다. 파일명, API 경로·프로시저, JSON 키, DB 모델·필드, 소스 경로, 열거값 및 FR/QA/화면 ID는 정확한 대조와 도구 호환성을 위해 원문을 유지합니다.

화면 이미지는 관찰 당시 운영 플랫폼의 실제 캡처입니다. 이미지 안의 영어 UI와 콘텐츠는 그대로 두고 제목·설명을 한국어로 번역했습니다. 제공받은 원본 ERD SVG도 변경하지 않았습니다. 이 자료는 내부 팀용이며 필요한 검토 계정·직원명·강좌명이 일부 보입니다. 비밀번호·세션 토큰·초대 비밀값은 포함하지 않습니다.

## supporting 폴더 안내

- `00-requirements-traceability.csv`: 요구사항, 화면, 시퀀스, QA, API 및 데이터 연결표.
- `02-screen-reference.md`, `02-screenshot-catalog.json`, `02-screenshots/`: 실제 화면 47개의 설명·출처·캡처 시각·이미지. `02-screen-route-inventory.csv`는 소스 페이지 진입점 87개입니다. 캡처는 선별 검토이며 모든 상태를 포괄하지 않습니다.
- `03-user-supplied-erd.svg`: 사용자가 제공한 원본 ERD. `03-erd.drawio`: 그룹별 편집 가능한 ERD. `03-complete-erd.mmd`: 전체 스키마 관계. 필드 사전·관계 CSV·SQL 제약 부록은 개발 참조입니다.
- `04-api-openapi.json`, `04-api-postman-collection.json`: 가져오기 가능한 API 명세. `04-api-procedure-reference.md`와 색인 CSV는 상세 검토용입니다.
- `06-sequence-01.mmd`~`06-sequence-10.mmd`: 개별 시퀀스 다이어그램.
- `00-file-manifest.json`: 한국어판 파일별 크기·SHA-256 및 검토 기준.

데이터 사전의 필드 선언 800개는 스칼라·열거형 580개와 ORM 관계 접근자 220개입니다. 물리 열 800개를 뜻하지 않습니다. 제공 ERD의 모델 이름은 대조했지만 모든 연결선을 개별 대조한 것은 아닙니다. OpenAPI 구조 검증만으로 모든 소스 정제·권한 규칙을 표현할 수는 없습니다.

## 관찰 범위 및 QA 상태

플랫폼 관리자, 학원 관리자, 팀장, 강사, 학생의 다섯 계정으로 로그인·탐색을 검토하고 공개 인증 폼도 확인했습니다. 검토 종료 후 로그아웃했습니다.

QA 상태는 **관찰됨 53건, 검토 필요 1건, 미실행 95건, 통과 0건**입니다. 관찰됨은 기록한 화면 확인만 뜻하며 인수 테스트 통과가 아닙니다. 이전 관찰 6건은 9월 26일 실행일을 유지하고 추가 캡처는 9월 28일입니다. 운영 환경에서 폼 저장·초대·가져오기·코드 실행·채점 제출은 수행하지 않았습니다. 작업 공간 진입만으로 학습 활동이 기록될 수 있습니다.

한국어판은 Word 전체 페이지와 슬라이드 및 각 시트의 대표 범위를 렌더링하여 검토했습니다. QA 상태 드롭다운과 요약 수식의 한국어 값을 일치시켰습니다. 문서 검증은 실제 애플리케이션 QA를 대체하지 않습니다.

## 파일 열기 및 유지보수

DOCX는 Word·Google Docs, PPTX는 PowerPoint, XLSX는 Excel·Google Sheets에서 엽니다. Excel의 수식·상태 유효성 검사를 유지하십시오. draw.io는 diagrams.net, SVG는 브라우저, Mermaid는 지원 편집기에서 엽니다. API JSON은 OpenAPI 3.1 뷰어·Postman에 가져와 비공개 스테이징 설정으로 사용합니다.

Word 한국어 서체는 Noto Sans CJK KR을 사용합니다. 서체가 없는 환경에서는 한국어 지원 글꼴로 대체될 수 있어 줄바꿈이 달라질 수 있습니다. 원본 식별자와 요구사항 ID를 유지하고 코드 변경 시 소스 기준 자료를 재생성하십시오. 애플리케이션 코드는 변경하지 않았습니다.
