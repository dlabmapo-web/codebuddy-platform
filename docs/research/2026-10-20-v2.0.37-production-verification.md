## Unresolved findings

### 1. Admin exercise page crashes

Reproduction: sign in as `cove-admin`, open Academy courses → the QA course →
QA automatic PDF grading. The page displays `This page stopped before it
finished`; Try again does not recover it.

Browser error: `useAcademySlug must be used inside an academy route`.
The shared authoring header imports `useAcademySlug` even when rendered by the
Admin route. Relevant source:
`packages/web/src/app/(studio)/academy/[academySlug]/(framed)/content/courses/[courseId]/lectures/[lectureId]/exercises/_components/exercise-header.tsx`.
Its academy-only return-to-problem link also needs appropriate surface handling.

### 2. Hidden reference PDF is missing from author preview

Reproduction: create an unpublished PDF/code exercise using a newly uploaded,
hidden PDF, then open its exercise title. Author preview loads the editor but
shows `The reference PDF is unavailable`. Reproduced again after hiding the QA
materials at the end. The standalone staff PDF reader works, and publishing the
PDF/course makes it render in the exercise.

`LearnService.buildWorkspace` calls `referencePdfMetadata`, which omits metadata
when the PDF material is hidden, including for an authorized author-preview
bootstrap. A correction must retain the student visibility boundary and the
delivery endpoint's authorization checks.

### 3. Staff dashboard completion still counts ungraded practice

After the Student solved the one automatic exercise, the Student course and
lecture correctly showed **1 of 1 solved**. The Manager overview's Learning
health row for the same QA class showed **50% exercise completion**, with only
the automatic and ungraded programming exercises visible. The Team Lead course
reach also treated the ungraded-only course as having a completion denominator
before the automatic exercise was added.

The Manager overview calculation uses `entry.materialIds.length` for assigned
exercises. Its analytics projection needs to exclude Practice only consistently
with the learning projection. The platform course list also labels the ungraded
fixture under No tests; that is an additional audit-label symptom, not a failed
automatic grading case.
