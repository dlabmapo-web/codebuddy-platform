# Local verification evidence

These screenshots show an isolated **temporary test harness**, not a proposed
course-builder layout or a product page. The harness wrapped the real dotted
drag handle/provider, three-dot row menu, move dialog, reference picker and PDF
renderer, and used real CourseService/PdfDocumentService with disposable local
PostgreSQL. It bypassed the Next/Supabase sign-in shell and used a local fixture
PDF instead of production storage. It was removed after the check.

The production course-builder layout/styles, dotted handles, menu and move
dialog are preserved. These images are evidence of the two move interactions
and retained PDF rendering, not screenshots of a shipped replacement UI.
