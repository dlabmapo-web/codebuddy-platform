## Implementation decisions

- Keep the existing navigation, autosave, collaboration and grading services. Rearrange the student workspace controls to match slides 28–34: separate menu toggle, vertical input/output, centred bottom navigation, and one output region with Reset / Test run / Run / Submit.
- Test run processes public samples sequentially through the existing Python worker, preserves every result, and cancels the queue on Stop or unmount. Hidden cases remain server-only.
- Team leads receive enrollment permission as requested by slide 18, without receiving membership administration or password access. Student renaming is a separate endpoint, bounded to an active student in the same academy; it updates the academy display name and audit log atomically, without changing the global identity.
- Treat a temporary session-store error as a retryable heartbeat failure. Continue to disconnect expired student sessions. Avoid replacing an already matching Monaco buffer during collaboration rebinding.
