# Short-answer and quiz staff actions

Branch: `feat/dlab-os-staff-sso`. This is a local implementation; production has not been changed.

The shared assessment header now exposes View solution, Tutoring and Edit according to server-issued capabilities. It is present on personal practice/preview and student-answer review pages. Cove's existing blue tokens, Lucide icons, accessible drawers and author dialog are reused. The question is expanded when reviewing student work.

| Held grants | Activity actions |
| --- | --- |
| Teacher | Private solutions and tutoring for assigned classes |
| Team Lead + Teacher | Solutions, content editing and assigned-class tutoring |
| Manager + Team Lead + Teacher | Solutions, content editing and assigned-class tutoring |
| Student | Own answer, submission and feedback; no staff controls or answer key |
| Platform inspection | Reference reading where already authorized; no new teaching or write bypass |

Tutoring opens the existing class-scoped learner roster and grading/feedback workspace. The return link opens personal practice again. Edit changes the question/configuration through the existing editor, with published answer-definition locks and revision checks intact. It does not change submitted student answers. Short-answer and multiple-choice questions have no editable student draft; staff publish a grade and feedback against an immutable submission.

The API lists only active classes where the current staff member is a real homeroom or assistant teacher and the course is assigned. A pure Teacher cannot open an unassigned course. Managers and Team Leads retain curriculum access, but management rank does not grant tutoring access. Removing assignment blocks subsequent roster/review requests. Ordinary accounts keep their explicitly held grants; SSO role derivation is unchanged by this extension.

## Manual check

1. Sign in as a Teacher, Team Lead or Manager with a class assignment. Open that class's course and a short-answer or multiple-choice activity.
2. Open **View solution** to see the private reference. Close the drawer.
3. Open **Tutoring**, choose an assigned class, then select a learner in the learner selector.
4. Read the question and submitted answer. Set a score/completion status, enter feedback and select **Publish review**.
5. Sign in separately as the student and reopen the activity. Confirm the score/feedback appear and the original submitted answer is unchanged.
6. As Manager or Team Lead, select **Edit**, change an allowed field and save. Reload before trying the revised question. Teacher and Student should not have this action; direct unauthorized save requests must also fail.
7. Remove the staff class assignment through class management. Confirm the roster/review API refuses the old class URL and a fresh class list no longer contains it.
